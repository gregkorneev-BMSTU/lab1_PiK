# Лабораторная работа №1 — основы Python

Консольные программы для поиска действительных корней биквадратного уравнения:

```text
A · x⁴ + B · x² + C = 0
```

## Состав работы

| Файл | Парадигма |
| --- | --- |
| `procedural.py` | Процедурная: функции и `def` |
| `oop.py` | Объектно-ориентированная: класс `Equation` |
| `functional.py` | Функциональная: сопоставление с образцом `match/case` |
| `test_lab1.py` | Минимальная автоматическая проверка |

Все варианты вычисляют дискриминант, выводят только действительные корни и обрабатывают вырожденные случаи при нулевых коэффициентах.

## Требования

- Python 3.9+ для процедурного и ООП-вариантов;
- Python 3.10+ для `functional.py`, поскольку в нём используется `match/case`.

Внешние библиотеки не требуются.

## Запуск

Коэффициенты можно передать в командной строке:

```bash
python3 procedural.py 1 -5 4
python3 oop.py 1 -5 4
python3.10 functional.py 1 -5 4
```

Если аргументы отсутствуют, программа запросит `A`, `B` и `C` интерактивно. Некорректный коэффициент игнорируется и запрашивается повторно.

Пример результата для `A = 1`, `B = -5`, `C = 4`:

```text
Дискриминант: 9
Действительные корни: -2, -1, 1, 2
```

## Проверка

```bash
python3 test_lab1.py
```

На Python 3.9 тест проверяет процедурную и ООП-версии и сообщает, что функциональная требует более новую версию интерпретатора. На Python 3.10+ проверяются все три реализации.
