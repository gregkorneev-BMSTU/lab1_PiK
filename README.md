# Лабораторная работа №1 — основы Python

Консольные программы для поиска действительных корней биквадратного уравнения:

```text
A · x⁴ + B · x² + C = 0
```

## Состав работы

| Файл | Парадигма |
| --- | --- |
| `python/procedural.py` | Процедурная: функции и `def` |
| `python/oop.py` | Объектно-ориентированная: класс `BiquadraticEquation` |
| `python/functional.py` | Функциональная: сопоставление с образцом `match/case` |

Все варианты вычисляют дискриминант, выводят только действительные корни и обрабатывают вырожденные случаи при нулевых коэффициентах.

## Требования

- Python 3.9+ для процедурного и ООП-вариантов;
- Python 3.10+ для `functional.py`, поскольку в нём используется `match/case`.
- Коэффициенты вводятся с клавиатуры как целые числа.

Внешние библиотеки не требуются.

## Запуск

Запустите нужную программу:

```bash
python3 python/procedural.py
python3 python/oop.py
python3.10 python/functional.py
```

Программа по очереди запросит `A`, `B` и `C`. Если вместо целого числа ввести текст, коэффициент будет запрошен повторно.

Пример результата для `A = 1`, `B = -5`, `C = 4`:

```text
Дискриминант: 9.0
Корни: 2.0 -2.0
Корни: 1.0 -1.0
```
